GALLERY PHOTOS — Chaaye Khana, Jhelum (GT Road branch)
=====================================================

Drop your photos into THIS folder using these exact names, then refresh the
site. Each one fills its tile automatically — no code changes needed. Until a
file exists, its tile stays a labelled "ADD PHOTO" slot.

  atmosphere-1.jpg   → large featured tile  (the dining room / overall vibe)
  food-1.jpg         → a plated dish
  outdoor-1.jpg      → the outdoor / courtyard seating
  indoor-1.jpg       → the indoor seating area
  food-2.jpg         → another dish
  atmosphere-2.jpg   → another interior / atmosphere shot

RULES (as you asked):
  - Use ONLY photos of the Chaaye Khana JHELUM, GT Road branch.
  - Their own feed is instagram.com/chaaye_khana_jhelum.
  - Do NOT use photos of other Chaaye Khana branches or any stock / other
    restaurant images.
  - Make sure you have the right to use each photo (your own, or permission
    from whoever took it).

TIPS:
  - Landscape JPGs, ~1600px wide, is plenty. Keep each file under ~400 KB.
  - Want more/fewer tiles or different categories? Edit the <button
    class="gallery-grid__item"> list in index.html (#gallery) and add matching
    files here.
  - You can also point a tile at a hosted image instead: change its
    src="assets/gallery/food-1.jpg" to the full https:// URL.
